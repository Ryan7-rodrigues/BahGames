# Bah Games 🎮

Sistema desktop de distribuição digital de jogos para PC, desenvolvido como projeto final da disciplina de Programação Orientada a Objetos 2

* **Ryan Rodrigues**
* **Nicolas de Brito**

## 🎯 Objetivo
Desenvolver uma aplicação desktop para gerenciar um catálogo de jogos digitais, permitindo a aquisição direta de títulos, a organização da biblioteca pessoal de cada usuário e a geração de relatórios gerenciais de vendas e catálogo.

## 😨 Problema
O mercado atual de distribuição digital de jogos para PC apresenta alta centralização. O **Bah Games** surge como uma alternativa focada em simplicidade e desempenho, oferecendo uma interface direta, preços acessíveis e organização prática dos jogos adquiridos pelo jogador.

## 👪 Público-Alvo
Jogadores de pc de todas as faixas etárias que buscam uma plataforma leve para adquirir e organizar seus jogos digitais, além de administradores responsáveis pela gestão do catálogo e acompanhamento de vendas.

## ⌨️ Principais Funcionalidades
* **Autenticação e Gestão de Usuários:** Cadastro, edição, listagem e exclusão de clientes e administradores, com controle de acesso via tela de login.
* **Gestão de Catálogo (Jogos e Categorias):** CRUD completo para cadastrar, atualizar, listar e remover jogos e seus respectivos gêneros/categorias.
* **Loja com Filtros Otimizados:** Consulta personalizada de jogos disponíveis por título e categoria.
* **Compra Direta e Biblioteca Pessoal:** Aquisição simplificada de jogos em um clique, vinculando automaticamente os títulos comprados à biblioteca do usuário logado.
* **Relatórios Gerenciais:** Geração de relatórios em PDF via JasperReports com o histórico de vendas e o catálogo de jogos[cite: 1, 2].
